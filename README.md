# MagnaRunner — dev

Dev channel: volatile features for remote development testing. Updates do not change the separate Beta site.

Open the GitHub Pages link shown in this repository’s About section on your phone or desktop browser. Portrait is recommended. Drag to steer and split the robots.

This repository contains the compiled playtest build only. The Unity project and design documents remain in the private development repository. Game source revision: `2294ed4d95ef262b951fd695acc96f7abc0ccbbc`.

Build identity and served file hashes are in [build-info.json](build-info.json). This is a prototype for feedback; physical-device compatibility and performance are still being tested.
